| Suggested time | What to show |
|---|---|
| 0:00-0:45 | All four members appear and each introduces their full name and student ID clearly |
| 0:45-1:30 | Briefly explain Bristol Food Network, the enterprise boundary and selected Use Case 1 |
| 1:30-4:00 | Walk through the strategic model: six responsibility areas, external participants, interactions and independent business cycles |
| 4:00-5:30 | Explain candidate F1/F2 boundaries, important exception cases and the current tutor-confirmation status |
| 5:30-7:15 | Show the real Kanban board, task allocation, backlog, planning/tracking and Git commits; explain actual progress and outstanding work |

| 9:00-9:30 | State open issues, next-sprint work and summarize the demonstrated progress |
