RUBRIC AND COMPLETION GATES
30% — i* Strategic Dependency and Strategic Rationale:
  Actual readable SD and SR models, actors, dependencies, internal rationale,
  goals/qualities, tasks/resources, stakeholder expectations and consistent scope.
35% — Two detailed operational BPMN models:
  F1/F2, correct ownership, relevant alternative/exception paths and consistency
  with the strategic model and i*. Record the agreed function scope.
25% — Initial Camunda automation:
  Executable models, human tasks/forms, variables, gateway/business logic and
  initial service implementations where appropriate. Demonstrate running core
  paths. Static XML, Form Preview and Python tests alone do not meet this gate.
10% — Progress, traceability and version control:
  Explain i* → strategic → operational → implementation links, iterations,
  actual contributions and task status with accessible repository/PM evidence.

Full robust end-to-end integration is developed further in Sprint 3. For
Sprint 2, demonstrate meaningful executable core paths and state prototype
boundaries accurately. Do not add every possible BPMN symbol without a purpose.
